## Procedure (identical to NASDAQ's, see `LETTER_STATUS.md` there for the fully-worked-out version)

1. Check this board and the NASDAQ `LETTER_STATUS.md` — confirm no other agent (either exchange) is currently active.
2. Pick a letter marked `NOT STARTED`, claim it here (Status → `IN PROGRESS`, fill Claimed by), save before doing any real work.
3. Rigorously verify eToro login (see `NYSE_PROJECT_LOG.md`) before starting.
4. Work the letter's tickers in sorted order (from `nyse_data.tsv`, no need to scroll eToro's screener — completeness already verified), per the v3 method + mandatory human-paced protocol.
5. Log progress in `SESSION_LOG_NYSE_<LETTER>.md`, update this board's row at each checkpoint.
6. On any block (login lockout, CAPTCHA, Cloudflare): stop immediately, checkpoint cleanly, report back — never solve/bypass.
7. Before declaring a letter done: run the completeness audit (diff against `nyse_data.tsv`).
